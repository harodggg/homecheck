# homecheck — 产品定义（草案 v0.1）

> **状态：草案，等待确认。** 由 AI 起草，最终解释权归项目所有者。
> 最后更新：2026-09-13

---

## 1. 一句话定位

一个本机环境体检工具：只读扫描目录，产出人类可读报告和机器可读清单，
让你知道磁盘到底被什么占了、有哪些重复和残留。**默认绝不改动任何文件。**

## 2. 目标用户

- **主要用户**：本机所有者（单人使用，本地运行，无多用户场景）
- **触发场景**：主目录变乱变慢时，想知道"什么在占地方"，
  并且要在**完全知情**的前提下才动手清理。

## 3. 目标（做什么）

| 编号 | 目标 | 说明 |
|---|---|---|
| G1 | 体积画像 | 按目录 / 文件类型统计占用，输出排行 |
| G2 | 大文件与陈旧文件识别 | 超过大小阈值、且长期未修改的文件 |
| G3 | 重复文件检测 | **内容级**判定，同名不同内容不算重复 |
| G4 | 配置目录盘点 | 列出散落的 dotfiles / dotdirs |
| G5 | 报告输出 | 终端表格 + JSON（可被其他脚本消费） |
| G6 | 建议清单 | 为发现的问题给出候选动作 —— 但**只是建议** |
| G7 | 安全执行 | 显式 `--apply` + 逐条确认 + 执行前备份清单，三者齐备才可能移动/删除 |

## 4. 非目标（明确不做）

> ⚠️ **这一节是硬边界，不是"以后再说"。**
> 任何一条要改，必须写进 `DECISIONS.md` 并记录理由。

| 编号 | 不做 | 备注 |
|---|---|---|
| N1 | 不做图形界面 | 只做命令行 |
| N2 | 不做云同步 / 多机协同 | 纯本地 |
| N3 | **永不自动删除或移动文件** | 没有显式确认就绝不改动；这是本项目的核心承诺 |
| N4 | 不做文件内容搜索 / 全文索引 | 为查重而计算 hash 不在此列 |
| N5 | 不做常驻进程 / 实时监控 | 一次性运行，跑完退出 |
| N6 | 不为网络盘 / 外接盘做特殊性能优化 | 按本地磁盘假设设计 |

## 5. 成功标准（可验收）

- **S-A 鲁棒性**：在整个 home 目录上扫描不崩溃；遇到无权限目录
  （例如 `.Trash/`）跳过并如实汇报，不静默吞掉
- **S-B 正确性**：重复检测在测试夹具上结果与预期**完全一致**，
  包括边界情况（空文件、同大小不同内容、符号链接）
- **S-C 安全性**：默认模式下**零写入**。可通过对比扫描前后的文件系统快照证明
- **S-D 可用性**：home 目录量级扫描耗时在可接受范围内（阈值待定，见 Q7）
- **S-E 可消费性**：JSON 输出有稳定 schema 且有文档，字段名变更视为破坏性变更

## 6. 术语

| 术语 | 含义 |
|---|---|
| 扫描根 / root | 本次扫描的起始目录 |
| 大文件 | 体积超过阈值的文件（阈值待定，见 Q3） |
| 陈旧文件 | 最后修改时间早于阈值的文件（阈值待定，见 Q2） |
| 重复组 / duplicate group | 一组内容完全相同、但路径不同的文件 |
| 建议 / suggestion | 工具输出的候选动作，**无副作用** |
| 动作 / action | 真正改动文件系统的操作，**必须显式授权** |

## 7. 切片计划（概要）

| 切片 | 内容 | 验收方式 |
|---|---|---|
| S1 | 只读扫描 + 体积统计，终端打印表格 | 跑一遍，人工核对结果合理 |
| S2 | 重复文件检测（先按大小分组，再算 hash） | 对测试夹具结果精确匹配 |
| S3 | 报告导出 JSON + Markdown | 检查 schema 与文档一致 |
| S4 | 建议引擎（规则驱动） | 检查建议**不产生任何副作用** |
| S5 | 安全的 apply 流程（dry-run / 备份清单 / 逐条确认） | 故意误操作，验证不会误伤 |
| S6 | 测试补齐 + 边界情况（符号链接、权限拒绝、空文件） | 测试全绿 |

## 8. 已决事项（2026-09-13 确认）

> 以下 7 项已由项目所有者确认，取值即原"我的倾向"。
> 正式记录见 `DECISIONS.md` 的 ADR-0006。

| 编号 | 问题 | 决定 |
|---|---|---|
| Q1 | 默认扫描根 | **当前目录**；扫 home 需显式传参 |
| Q2 | "陈旧"的阈值 | 180 天，可配置 |
| Q3 | "大文件"的阈值 | 100 MB，可配置 |
| Q4 | 符号链接 / 空文件 | 不跟随符号链接；空文件**不**算重复 |
| Q5 | 清理方式 | **v1 只输出命令，工具自身不执行删除** |
| Q6 | 权限拒绝时 | 跳过并记录，结尾汇总 |
| Q7 | 性能目标 | 待 S1 基线数据后确定 |
