## 1. 本切片范围

**做**：
- 遍历一个目录树
- 统计文件数、目录数、总体积
- 按顶层子目录聚合体积，输出排行
- 按文件扩展名聚合，输出分布
- 终端打印报告

**明确不做**（属于后续切片，本切片一行都不写）：

| 不做 | 归属 |
|---|---|
| 重复文件检测 | S2 |
| JSON / Markdown 导出 | S3 |
| 建议引擎 | S4 |
| 任何写入、移动、删除 | S5（且受 N3 约束） |
| 图形界面、进度条 | 永不 / 待议 |

`scan.py` / `report.py` 在本切片内必须是**纯只读**的。

## 2. 命令接口

```
homecheck [路径] [选项]
```

**位置参数**

| 参数 | 说明 | 预填值 |
|---|---|---|
| `路径` | 扫描根 | 可选，**默认当前目录**（Q1） |

**选项**

| 选项 | 说明 | 预填值 |
|---|---|---|
| `--top N` | 体积排行显示前 N 项 | 默认 20 |
| `--max-depth N` | 限制遍历深度 | 默认不限 |

`--json` 本切片**不加**（属于 S3）。先不加，避免提前锁死输出契约。

**退出码**

| 码 | 含义 |
|---|---|
| 0 | 正常完成（即使有部分目录没权限） |
| 1 | 参数错误 |
| 2 | 扫描根不存在 / 完全不可读 |

## 3. 预期输出样例

```
$ homecheck ~/Downloads --top 5

homecheck — 扫描报告
扫描根   ~/Downloads
完成于   2026-09-13 14:02:11    耗时 1.24s

总体
  文件   12,430 个
  目录      892 个
  占用   18.4 GB

体积排行（前 5 项）
  1    6.21 GB   33.8%   video/
  2    3.05 GB   16.6%   datasets/
  3    2.44 GB   13.3%   installers/
  4    1.02 GB    5.5%   archives/
  5    0.88 GB    4.8%   photos/

文件类型分布（前 5）
  .mp4    6.21 GB   33.8%
  .zip    2.11 GB   11.5%
  .csv    1.44 GB    7.8%
  .dmg    1.02 GB    5.5%
  (无扩展名)  0.31 GB   1.7%

未扫描目录（权限不足，1 个）
  ⚠ locked/                    Permission denied
```

**这个样例本身是规格的一部分**，请重点看三处：

1. **数字要对得上** —— 排行百分比之和 ≤ 100%，且与总额自洽
2. **未扫描目录必须显式列出**，用 `⚠` 标出，不能静默吞掉（Q6）
3. **不依赖颜色**传达信息 —— 管道重定向后 `⚠` 仍然可读

## 4. 验收清单

S1 交付时必须逐条验证：

- [ ] `homecheck <目录>` 正常输出报告，格式与样例一致
- [ ] **不传路径时扫当前目录，绝不默认扫 home**（Q1）
- [ ] 权限不足的目录被列出且不影响整体扫描继续（Q6）
- [ ] **扫描全程零写入** —— 可用扫描前后文件系统快照对比证明
- [ ] 不跟随符号链接，同一个文件不被重复计数（Q4）
- [ ] 隐藏文件计入统计，但不在报告中单独展开
- [ ] 空目录、超大目录、超长文件名、含空格与中文的路径均不崩溃
- [ ] 单元测试覆盖：体积统计、扩展名聚合、权限异常处理

## 5. 本切片依赖的未决问题

| 编号 | 是否影响 S1 | 预填值 |
|---|---|---|
| Q1 扫描根默认值 | ✅ 影响 | 默认当前目录 |
| Q2 陈旧阈值 | ❌ 不影响 | — |
| Q3 大文件阈值 | ✅ 影响（排行口径） | 100 MB |
| Q4 符号链接 / 空文件 | ✅ 影响 | 不跟随符号链接 |
| Q5 清理方式 | ❌ 不影响 | — |
| Q6 权限拒绝处理 | ✅ 影响 | 跳过并记录 |
| Q7 性能目标 | ✅ 影响（耗时数字） | 先测基线再定 |

**Q1、Q3、Q4、Q6 是 S1 的前置条件**，这四项定了就能开工。
