# S5 规格：安全执行计划（dry-run + 审计清单）

> **状态：已实现。** 决策点列在第 0 节，逐条可否决。

---

## 0. 关键冲突与取舍

`PRODUCT.md` 的 **G7** 说：显式 `--apply` + 逐条确认 + 执行前备份清单，
三者齐备才可能移动/删除。
`PRODUCT.md` 第 8 节的 **Q5** 说：**v1 只输出命令，工具自身不执行删除。**

**这两条是冲突的。** 本切片遵循 **Q5**，理由：

1. Q5 是所有者针对"清理方式"专门拍的板，比 G7 的概述更具体
2. Q5 确认的时间更晚
3. 出错时更安全：不执行的工具无法销毁数据

**结论：S5 v1 = 生成可复核的执行计划，不执行任何改动。**
G7 中"真正执行"的部分**未实现**，需要明确授权后另开切片。

## 1. 范围

**做**：
- `--plan` 生成执行计划（dry-run）
- 计划内容：动作清单（路径 / 体积 / sha256 / 保留项 / 理由）、可回收总量、
  一条复核用命令、被安全规则拒绝的项
- `--max-actions N` 限制列出数量（默认 100，超出部分报数）
- JSON 输出新增 `plan` 字段，可作为变更前的**审计清单**归档

**不做**（明确划线）：
- 任何实际的删除或移动（Q5）
- `--apply` 选项
- 备份文件的创建 —— 因为不执行，没有东西需要备份
- 回收站集成

## 2. 安全规则（宁可少删）

任何一条命中，该路径都**不会**进入计划，而是记入 `refusals` 并**显式展示**：

| 规则 | 拒绝理由 |
|---|---|
| 不在扫描根之下 | 防止计划越界到根外面 |
| 含 `.git` / `.hg` / `.svn` / `.Trash` 分量 | 删除会破坏版本库或回收站数据 |
| 与保留项同 `(device, inode)` | 硬链接，删除不会释放空间 |
| 等于扫描根或保留项 | 防御性拒绝 |

**被拒项不静默丢弃** —— 用户能看到"工具本来想删但被拦下了什么"。

## 3. 命令生成约束

- 路径一律 `shlex.quote` 转义（含空格、引号也安全）
- **绝不使用 `-r` / `-f`**，因此只作用于普通文件
- `rm` 之后紧跟 `--`，防止以 `-` 开头的文件名被当作选项
- **本工具永不执行这些命令**

## 4. 验收清单

- [x] `--plan` 输出计划，且**执行后目标文件依然存在**
- [x] 计划生成过程零写入（单元测试用 mtime 快照验证）
- [x] 硬链接不被纳入计划
- [x] `.git` 内的路径被拒绝并给出理由
- [x] 扫描根之外的路径被拒绝
- [x] `--max-actions` 截断时如实报告剩余数量
- [x] 命令经转义，含空格/单引号的路径不被破坏
- [x] JSON 的 `plan` 字段结构稳定，未请求时为 `null`
